# Suburwise Data Management Tracker

## 1. Project Overview
Suburwise Data Management Tracker is a full-stack web application designed to manage, organize, distribute, and track sales data.

## 2. Project Objectives
- Secure Login and Signup
- Manage sales data
- Upload Excel files
- Distribute data to sales managers
- Track shared data
- Calendar-based data distribution history
- Dashboard and reports

## 3. Technology Stack

### Frontend
